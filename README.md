👁️ Village Eye Care – Landing Page
Welcome to the Village Eye Care Landing Page project! This is a simple and responsive landing page built using HTML with inline CSS. It is designed to promote and spread awareness about eye care services in rural or village areas.

🌟 Features
Clean and professional layout

Inline CSS (no external stylesheet required)

Responsive design suitable for desktop and mobile

Easy to customize text and images

Includes a navigation bar, about section, services, and contact info

🛠️ Technologies Used
HTML5

Inline CSS
